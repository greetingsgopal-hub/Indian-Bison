# Conversion Copywriter Skill

## Core Directives

1. **Zero Generic Placeholder Copy**
   - **BANNED**: *"Welcome to our platform"*, *"Your all-in-one solution"*, *"We provide high-quality services"*, *"Click here"*, *"Submit"*, or *"Learn More"*.
   - **REQUIRED**: Every headline, subheadline, microcopy string, and CTA must state a specific outcome, quantify value (in ₹ INR, hours saved, or patients/walk-ins gained), and address the target persona directly.

2. **Problem–Agitation–Solution (PAS) Framework**
   - **Problem (P)**: Call out the exact observable bottleneck (e.g., missing Google Maps website link, unconfirmed evening OPD hours, dropped phone calls).
   - **Agitation (A)**: Quantify the cost of inaction (e.g., losing high-ticket ₹25,000 Dental Implant or ₹10,000 RCT+Crown walk-ins to nearby corporate chains like Clove Dental).
   - **Solution (S)**: Present the transformation as an effortless, turnkey mechanism (e.g., *"Launch a 24/7 WhatsApp Slot Booking Assistant & Fast Mobile Clinic Page in 5 Days"*).

3. **High-Conversion UI Patterns**
   - **Above-the-Fold Value Proposition Clarity**: The user must understand *who it is for*, *what problem it solves*, and *the measurable ROI* within 3 seconds of page load.
   - **Prominent Trust Badges & Social Proof Blocks**: Always pair claims with quantified proof (verified Google review counts, local sector benchmarks, doctor testimonials, SSL/DPDP security badges).
   - **Single Clear Primary Action Per Screen**: Eliminate competing primary buttons. Every view must guide the user toward one unmistakable primary action (e.g., `"Book My Free 5-Min Clinic Demo on WhatsApp"`).

4. **Micro-Offer & CTA Engineering**
   - Replace high-friction asks (*"Buy Now"*, *"Schedule a 45-Min Consultation"*) with low-friction, value-first micro-offers (*"Get My 1-Minute Custom Audio Audit"*, *"Preview My Clinic's Live Booking Prototype"*).
