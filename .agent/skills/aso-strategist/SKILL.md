# ASO Strategist Skill

## Core Directives

Whenever building or updating a mobile client, PWA wrapper, or desktop/mobile web app:

1. **Deliver a Complete App Store & Google Play Metadata Package (`aso-metadata.json` / `ASO_PACKAGE.md`)**
   - **App Name (<= 30 chars)**: High-intent keyword + brand name (e.g., `Indian Bison: Local Lead CRM`).
   - **Subtitle / Short Description (<= 30 chars iOS / <= 80 chars Play Store)**: Clear outcome-focused value proposition.
   - **Promotional Text (<= 170 chars)**: PAS-driven hook highlighting immediate ROI.
   - **iOS Keyword Field (<= 100 chars, comma-separated, no spaces)**: High-volume, low-difficulty commercial keywords.
   - **Full Description (<= 4000 chars)**: Structured with problem-agitation-solution opening, bulleted feature transformations, social proof, and compliance disclosures.
   - **Release Notes ("What's New")**: Value-oriented changelog for every build.

2. **Mobile Onboarding & First-Session Conversion**
   - Enforce a single primary action per onboarding screen.
   - Display immediate value (pre-loaded live leads + ₹ quotation estimates) before asking for complex configuration.
